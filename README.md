# School Portfolio

A school works portfolio for Khen Mhar B. Ilao, built with plain HTML, CSS, and JavaScript.

## Publish on GitHub Pages
1. Create a new repository on GitHub.
2. Upload everything inside this folder (not the folder itself) to the repository.
3. Go to Settings, then Pages, choose the main branch, and save.
4. Your site goes live at https://YOUR-USERNAME.github.io/REPOSITORY-NAME/

## Edit your content
Open `data/content.js`. Every piece of text on the site is in that one file.
Anything that starts with [PLACEHOLDER] shows with a soft highlight on the site.
Replace the text and remove the [PLACEHOLDER] part.

- Add a course: copy one course block inside `courses` and edit it.
- Add an artifact: copy one artifact block inside a course's `artifacts`.
- Add an achievement: copy one line inside `achievements`.

## Add your files
- PDFs go in the `files` folder. Example: `file: "files/my-report.pdf"`
- Certificate images go in `assets/img/achievements`. Example: `file: "assets/img/achievements/cert.jpg"`
- Your profile photo is `assets/img/profile.jpg`.
- Web links: `file: "https://your-link.com"`

## Change the navigation
Edit the `NAV` list near the top of `assets/js/app.js`.
